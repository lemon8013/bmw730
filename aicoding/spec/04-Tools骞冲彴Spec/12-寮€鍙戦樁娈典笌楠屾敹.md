# 12 开发阶段与验收

## T1 平台基础
实现：
- Tool/Category/Version
- Registry
- 管理 CRUD
- 状态/发布
- API
- 数据库迁移
- 单元测试

验收：能创建工具、注册组件、发布、下线。

## T2 工具前台
实现：
- 首页
- 分类
- 搜索
- 工具详情/工作区
- 动态加载

验收：工具不需要硬编码到首页。

## T3 执行框架
实现 FRONTEND/BACKEND/ASYNC 抽象。

验收：至少一个 FRONTEND 工具和一个 BACKEND 示例通过统一 Runtime。

## T4 访问与额度
实现：
- GUEST anonymous_id
- USER user_id
- policy
- daily limit
- rate limit
- Redis 原子计数

验收：并发下不能明显绕过额度。

## T5 统计
实现 Usage Event、Daily Statistics、后台统计。

验收：执行一次能形成统计事件；聚合结果正确。

## T6 热门
实现今日/7日/30日/累计排行，默认首页近7日。

## T7 首批工具
先完成 JSON、Base64、URL、时间戳、UUID、文本 Diff、文本处理、Regex 等。

## T8 全量工具
按既定工具目录逐步实现。

## 每阶段
完成后必须：
1. 运行 lint/type check
2. 单元测试
3. API 测试
4. 权限测试
5. 安全测试
6. 数据库迁移验证
7. 更新文档
8. 输出 `PHASE X STATUS: READY FOR VERIFICATION`

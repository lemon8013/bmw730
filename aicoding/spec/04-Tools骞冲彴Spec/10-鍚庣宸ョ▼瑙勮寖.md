# 10 后端工程规范

## 技术
沿用现有 Python + FastAPI + SQLAlchemy + Alembic + PostgreSQL + Redis。

## 分层
API/Router → Service → Repository → Model。

## 核心服务
- ToolService
- ToolAccessService
- ToolRuntimeService
- UsageService
- StatisticsService
- PopularityService

## 原则
- AuthorizationService 负责授权。
- ToolAccessService 负责开放与额度。
- UsageService 负责事件。
- StatisticsService 负责聚合。
- Redis Key 集中定义。
- 所有关键变更写 Operation/Audit Log。
- 不在 Service 中散落主体判断。

## 事务
工具配置、发布、策略变更按现有数据库事务规范实施。

## 并发
额度递增使用 Redis 原子操作/脚本等可靠方案；不得采用“先 GET 再 SET”的非原子实现。

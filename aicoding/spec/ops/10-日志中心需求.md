# 10 日志中心需求

## 日志类型
- Application Log
- Access Log
- Security Log
- Operation Log
- System Log

## 查询
time、level、service、host、trace_id、request_id、keyword、IP。

## 展示
- 时间线
- 详情
- Trace 跳转
- 上下文日志
- 关联事件/告警

## 脱敏
永不展示：
- password
- MFA secret
- access token
- authorization header
- API key
- 用户上传的敏感原文

日志存储技术不在本文件冻结。

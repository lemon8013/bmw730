# 12 事件中心需求

事件与指标、日志、告警分离。

典型事件：
- service down
- host offline
- agent offline
- job failed
- job timeout
- maintenance started/ended
- deployment/restart（如未来接入）
- alert triggered/resolved

事件支持：
- event_id
- event_type
- source
- resource
- severity
- occurred_at
- metadata
- trace_id/request_id（如有）

事件不得直接等同于告警。

# 22 审计需求

复用现有 `sys_audit_log`。

必须审计：
- Monitor 创建/修改/删除
- Alert ACK
- Alert Silence
- Alert Rule 修改
- Notification 配置修改
- Maintenance 修改
- Agent 启停/禁用等管理
- Job Retry/Stop
- Dashboard 管理
- 其他 Ops 配置变更

审计至少记录：
operator、action、resource、before、after、result、error、IP、UA、trace_id、request_id、created_at。

Audit append-only。

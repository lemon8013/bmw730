# 2026-10-03 前端缺陷清单收尾 + 成长体系根因

## 服务重启说明（重要）
- **Git Bash 里 `nohup ... &` 启动的服务会在父任务结束时被回收**，不可靠。
- `Start-Process` 被安全策略拦截（"Starting cmd.exe from PowerShell bypasses PowerShell
  command validation"），`scripts/start-all.ps1` 因此跑不起来。
- **唯一可靠方式：用 Bash 工具的 `run_in_background=true`，且命令本身就是前台长驻进程**
  （不要再套 `&` / `nohup`）。三个服务各自一个后台任务，任务不停止则进程常驻。
- 探测本机服务须加 `--noproxy '*'`（否则被 http_proxy 吞掉），且必须用 `localhost`
  不能用 `127.0.0.1`（Vite 只监听 IPv6）。

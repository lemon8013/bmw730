## 环境坑（新）
- playwright-cli 的守护进程**不跨 Bash 调用存活**：open/run-code/screenshot 必须在同一条命令里串完。
- 注入会话要三个键齐全：`vctn.ops.access_token` / `refresh_token`（**不能是空串**，readCredentials
  要求非空）/ `access_expires_at`，注入后必须 reload 让 store 重新引导。
- ops-web 路由前缀是 `/ops/*`（route-table.ts 白名单），不是 `/overview`。
- 运行中的后端是旧代码时不会自动加载新路由——改完 main.py 必须重启 uvicorn（kill PID 再后台重启）。
- 含密码/令牌字面量的命令会被敏感审批拦下：用 `.devtools/mint_token.py` 签发、用
  `run-code` + 本地 CORS 小服务（:5198 token_server.py）把 token 送进浏览器，避免命令行出现凭据。

============================================================
六、SQLAlchemy Model 规范
============================================================

使用：

SQLAlchemy 2.x

优先使用：

DeclarativeBase
Mapped
mapped_column

例如：

    __tablename__ = "sys_user"

    id: Mapped[int] = mapped_column(
        BigInteger,
        primary_key=True
    )

必须根据 DDL 精确映射。

例如 PostgreSQL：

BIGINT
    →
BigInteger

VARCHAR(n)
    →
String(n)

TEXT
    →
Text

BOOLEAN
    →
Boolean

INT
    →
Integer

DATE
    →
Date

TIMESTAMPTZ
    →
DateTime(timezone=True)

JSONB
    →
JSONB

INET
    →
INET

NUMERIC
    →
Numeric

不要自行替换数据库类型。

============================================================
七、NULL / NOT NULL
============================================================

DDL：

NOT NULL

必须对应：

nullable=False

DDL：

允许 NULL

必须对应：

nullable=True

不能自行改变。

============================================================
八、DEFAULT
============================================================

DDL 中的：

DEFAULT

必须准确映射。

例如：

DEFAULT FALSE

必须对应：

server_default

而不是自行变成 Python default。

数据库默认值优先保持数据库语义。

例如：

created_at TIMESTAMPTZ NOT NULL DEFAULT now()

Model 必须保持：

server_default=func.now()

============================================================
九、主键
============================================================

所有 BIGINT 主键：

必须：

primary_key=True

不要自动：

autoincrement=True

如果 DDL 没有定义数据库自增：

Model 不允许擅自增加自增。

因为本项目使用：

【Snowflake ID】

ID 由应用层生成。

列名
ondelete

禁止自行增加：

SET NULL

除非 DDL 已经定义。

十三、UNIQUE
============================================================

DDL 中：

必须完整映射。

包括：

联合 UNIQUE

必须使用：

    "b",
    name="..."
)

名称必须与 DDL 一致。

不能因为“业务层也会校验”而删除。

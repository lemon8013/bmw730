# 16 冻结项与待冻结项

## 已冻结

### 工程
- Admin 与 Tools 完全独立
- Vue3 + TypeScript + Vite
- Vue Router + Pinia
- 独立域名、构建、部署

### 身份
- `sys_user`：后台管理员
- `biz_user`：业务用户
- Tools 不处理 sys_user
- Tools 与 Blog 共用 biz_user

### Tool
- ToolRegistry
- ToolRuntime
- component_key
- FRONTEND/BACKEND/ASYNC
- UsageReporter
- Access API
- Usage API

### 游客
- anonymous_id 是主要额度身份
- IP 用于防刷/风险/限流
- IP 不是唯一游客身份

### 用户成长
- 成长值决定等级
- 积分独立
- 外观后端配置
- 前端不计算业务规则

## 暂不冻结

- UI 组件库
- 最终主题
- OAuth Provider
- MFA Provider
- Token 精确生命周期
- Error Code 新增段
- 最终 API DTO
- 热门排序 score 公式
- 积分过期
- 等级具体数值
- 积分奖励具体数值
- 积分商城
- 活动
- 邀请
- 完整任务/成就规则

## 数据库

数据库设计已经完成，本 Spec 不重新设计数据库。

实际 API 与本 Spec 冲突时，不得自行修改数据库、伪造 API 或绕过后端；必须报告接口契约冲突。

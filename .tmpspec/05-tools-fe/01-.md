# 01 项目边界与总体架构

## 1. 总体

```text
VCTN
├── vctn-admin-web
│   └── Admin 管理平台
├── vctn-tools-web
│   └── Tools 工具平台
└── FastAPI
    └── api.example.com
```

## 2. 现有 Admin

现有：

```text
frontend/
```

保持为管理平台前端，不将 Tools 页面加入其中。

## 3. 新建 Tools

建议：

```text
D:\project\bmw730-tools-web
```

独立 Git/工程、独立依赖、独立构建、独立发布。

## 4. 不允许源码依赖

Tools 不得 import Admin 的：

- Router
- Store
- View
- Layout
- 业务 Component
- Permission Logic
- Auth Store

Admin 也不得 import Tools。

## 5. 允许共享的是协议

通过 API Contract 共享：

- API Base URL
- Response Envelope
- Error Code
- Trace/Request ID
- ID 字符串规则
- 时间格式
- Auth 协议
- Tool/User DTO

不是共享源码。

## 6. 部署

```text
admin.example.com → Admin dist
tools.example.com → Tools dist
api.example.com   → FastAPI
```

Tools 必须能在没有 Admin dist 的情况下独立部署。

## 7. Tools 数据流

```text
/tools/:slug
   ↓
Tool API
   ↓
Tool Definition
   ↓
component_key
   ↓
ToolRegistry
   ↓
Tool Component
   ↓
ToolRuntime
   ↓
执行
   ↓
UsageReporter
```

## 8. 禁止架构

禁止把 Tools 做成 Admin 的菜单页面。
禁止通过 iframe 把两个站点拼成一个产品。
禁止依赖 Admin Web build。
禁止使用 Admin Router/Store 作为 Tools 的基础。

# 11-缓存、并发与幂等

## 1. Redis

Redis 用于：

- 权限缓存
- Session 辅助状态
- 登录失败计数
- 分布式锁（必要时）
- 权限失效通知
- 限流

## 2. 权限缓存

建议 Key：

```text
permission:user:{user_id}:version:{version}
```

具体 Key 结构可在实现阶段调整。

## 3. 即时生效

权限修改：

```text
DB Commit
 ↓
Invalidate Cache
 ↓
通知其他实例
 ↓
后续请求使用新权限
```

## 4. 并发

涉及：

- 用户状态
- Session
- 角色权限
- 字典排序
- 参数修改

需要考虑乐观锁或事务隔离。

## 5. 幂等

以下操作建议具备幂等能力：

- 启用/禁用
- Session 撤销
- MFA 启用/禁用
- 密码重置任务
- 权限更新

## 6. 分布式部署

Redis Pub/Sub 或其他机制保证多实例权限缓存一致性。

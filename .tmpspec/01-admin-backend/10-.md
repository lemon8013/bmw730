# 10-安全设计

## 1. 认证

- 密码使用 Argon2id
- Session 与 Token 关联
- Refresh Token 哈希存储
- MFA 可扩展
- 登录失败锁定

## 2. 密码

12 位；大小写；数字；特殊字符；最近 5 次不可重复；90 天有效；5 次失败锁 30 分钟；管理员重置后强制修改。

## 3. 授权

采用 RBAC + Data Scope。

后端 API 必须强制授权。

## 4. 超级管理员保护

超级管理员不能被其他管理员强制下线。

## 5. 数据权限

部门管理员只能操作：

```text
自己部门
+
所有下级部门
```

## 6. 日志安全

密码和 MFA Secret 绝对禁止记录。Token 仅允许前 6 位。

## 7. 防护

至少设计：

- 登录限流
- API 限流
- CORS
- CSRF 风险评估
- SQL 注入防护
- XSS 防护
- SSRF 风险控制
- 文件上传安全
- 安全 Header
- 输入校验
- 权限越权测试

## 8. 密钥

JWT/MFA 加密密钥不得硬编码进仓库，应通过安全配置/Secret 管理。

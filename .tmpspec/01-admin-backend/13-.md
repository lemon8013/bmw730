# 13-运维部署

## 1. 运行组件

```text
Nginx / Load Balancer
        ↓
FastAPI / Uvicorn
        ↓
PostgreSQL
        +
Redis
```

## 2. 配置

环境变量/Secret：

- DATABASE_URL
- REDIS_URL
- JWT_SECRET / signing key
- MFA encryption key
- LOG_LEVEL
- CORS_ORIGINS

禁止提交真实 Secret。

## 3. Migration

使用 Alembic：

```text
alembic upgrade head
```

## 4. 健康检查

提供：

```text
/health
/ready
```

区分进程存活与依赖就绪。

## 5. 日志

应用日志与审计日志分离。生产环境必须控制日志级别和敏感字段。

## 6. 数据备份

PostgreSQL 定期备份。Audit Log 按 2 年保存要求设计归档和备份策略。

## 7. 监控

监控：

- API 延迟
- 错误率
- DB 连接
- Redis
- CPU
- Memory
- Session 数
- 登录失败
- 锁定用户数

# 09 前端工程规范

## 技术
Vue 3 + TypeScript + Vite + Vue Router + Pinia。

UI 组件库暂不冻结，Agent 不得擅自替项目做不可逆选择。

## 建议结构
`src/`
- api/
- components/
- layouts/
- pages/
- router/
- stores/
- tools/
  - registry/
  - runtime/
  - definitions/
- utils/
- types/

## 工具注册
`ToolRegistry` 只允许编译期/代码注册安全组件。

## Store
至少：
- authStore
- toolStore
- categoryStore
- usageStore

## API Client
统一处理：
- Authorization
- X-Trace-ID
- X-Request-ID
- envelope
- 401
- 403
- 网络错误

## 类型
后端 BIGINT ID 使用 `string`。

## 前台权限
前端隐藏不可访问工具只是 UX；后端必须再次校验。

## 组件
工具工作区应提供统一壳层，具体工具只实现自身业务组件。

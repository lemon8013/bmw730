# 03 工具前台

## 页面
- `/` 首页
- `/category/:slug` 分类
- `/search` 搜索
- `/popular` 热门
- `/recent` 最近使用
- `/tool/:slug` 工具工作区

## 首页
搜索、热门工具、分类入口、工具卡片、最近使用。

## 动态数据
工具列表、分类、热门排行均从 API 获取，不硬编码工具清单。

## 工具工作区
统一提供：
- 标题/说明
- 输入区域
- 执行按钮
- 清空
- 复制
- 下载（工具支持时）
- 错误提示
- 执行耗时（适用时）
- 使用额度提示（适用时）

## 响应式
桌面端优先，同时兼容移动端。

## 隐私
输入内容默认只在浏览器内处理；不得因埋点自动上传输入内容。

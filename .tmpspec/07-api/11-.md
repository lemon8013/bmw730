## Platform

普通业务用户通过业务身份访问自身资源。
后台管理员不得通过普通 Platform API 身份绕过 Admin 权限。

## Field/Data Scope

所有 User/Department/Role 等管理 API 必须：
1. API permission
2. field permission
3. data scope

三者全部通过才执行。
